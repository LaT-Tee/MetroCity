## 这是什么

每个种子生成一座独一无二的城市：海岸、河流、缓坡与山、老城和卫星镇，还有每天要通勤的几百万居民。
一开始所有人都堵在路上。你的工作只有一件——**修地铁**。

线路修得好，通勤时间下降、客流上涨，人们搬到车站周围，街道向外延伸，农田变成街区，城市升级，地图解锁更大的范围。

## 玩法

| | |
|---|---|
| **画线** | 按住拖动即可画出线路，松手落站；也可以逐站点击。接到已有车站上就是换乘。 |
| **换乘** | 新线穿过旧线时会自动形成换乘站：附近有站就拐过去停靠，没有就在交叉点新建。 |
| **读图** | 人口、通勤时间、出行需求三种热力图，告诉你下一条线该修在哪。 |
| **助手** | 打开规划助手，它会按当前客流给出新线、延伸和环线的建议，一键采纳。建议是稳定的（同一座城同一个月，刷新多少次都一样），并且会照顾将来：城市委托、在建项目、还没通地铁的火车站和机场、有发展余地的地段。 |
| **快线与直通** | 市郊快线站少车快；两条线首尾相接且方向一致时，列车自动直通运转。 |
| **运营自动化** | 班次和快车由运营方自动安排：客流涨到值得的时候，线路会自动开行快车、特快，只升不降。你只管修网。 |
| **成长** | 每月结算一次：人口流向车站周边，街道生长，繁忙的街道拓宽，两岸建成后架桥。人口增长会放缓，受不了通勤的人会搬家；城市长大后会新建第二座火车站、客运站和机场。 |
| **城市委托** | 城里有新项目动工（体育场、科技园、度假区……）或者火车站、机场还没通地铁时，市里会委托你把站修到它旁边。按期完成，那一带会更繁荣。 |
| **成就与报告** | 26 项成就、年度回顾、可导出的线路图和规划报告。 |

## 观景模式

按 `V` 坐上一位通勤者的座位，跟着 TA 上车、换乘、到站。电脑上可以切到 **3D 视角**：

- **窗边座位**：第一人称看窗外的城市掠过，进了隧道就是隧道。
- **跟随镜头**：像无人机一样跟在列车后上方，提前看见楼和山并绕开或爬升；列车入地或进山后，镜头与它之间的一切会变成半透明，始终看得到车和前方一小段线路。
- **城市是从游戏本身长出来的**：沿街排布的住宅、公寓、写字楼和塔楼，公园、广场、游乐场、球场、学校、教堂、商场、图书馆、体育馆、医院和政府大楼；街道上有车，水上有船，天上有云。
- **一天的光影**：3D 里约六分钟过完一天——上午、正午、金色的傍晚、夜里万家灯火和路灯、星空，再到黎明。只有光在变，眼前的东西不会变。
- **地形是真的**：城市随着缓坡起伏，房子和街道贴着坡面；真正的山保留下来，陡处露出岩石，线路和铁路打洞穿过去；水面低于地面，河岸有坡，马路和铁路在桥墩上跨过去，船从桥下过。
- **线路有高低**：密集的市中心走隧道，出了城上高架，中间是坡道；两条线交叉时一条走上层或更深一层；每条线都是双轨，多线大站是并排的股道和分层的站台，站台处线路永远水平。
- **路有高度**：过河的路上桥，快速路在路口上方跨过普通路（立交），机场的出发层是一条真的高架路，从两端的坡道开上航站楼二楼，到达层在地面贴着一楼大门，两层再接回通往市区的路。
- **地标**：中央火车站（玻璃拱顶站棚、砖砌站房和钟楼）、客运站、机场（跑道、航站楼、出发层高架、停车场），以及城市发展出来的十三种项目——工业园、科技园、大学、海滨度假区、观景塔、主题乐园、古塔、温泉、集装箱港、剧院、金融双塔、市政厅、体育场，开业前是带塔吊的工地。

## 常识是硬规则

城市不是随便摆出来的。下面这些在生成时就被禁止，并且有一个自检函数在多座城市上逐条计数（控制台里 `__mc.dbg.audit()`，每一项都应当是 0）：

- 车站、建筑、公园、树、火车站、客运站、机场都不在水里；
- 机场、火车站、客运站和项目地块是保留地，路不从中间穿过，上面不盖别的东西；
- 建筑不压在路上，站口和站楼的整块占地都不压在路上，一个换乘站只有一座站楼（找不到空地就跨马路建两翼加连廊），车站建筑互不重叠；
- 桥墩和高架柱子不立在路上，船绕开桥墩；
- 线路不互相穿过，不贴着水面跑，站台处不带坡。

## 操作

| 按键 | 作用 |
|---|---|
| `1` `2` `3` | 浏览 / 画线 / 拆除 |
| `空格` | 画线时落站；选中线路时在线上加站 |
| `[` `]` | 切换选中的线路 |
| `A` | 规划助手（`Tab` 切换建议，`Enter` 采纳） |
| `V` | 观景模式（`N` 换一位乘客） |
| 工具栏 ♪ | 开关程序化生成的背景音乐 |
| `P` | 暂停 / 继续 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |

手机和平板上用触摸操作：单指拖动画线，停顿片刻落站，双指缩放。

## 本地运行

```bash
npm install
npm run dev      # 开发服务器，保存即刷新
npm run build    # 生成 dist/index.html：单个自包含文件，可直接双击打开或丢到任何静态托管
npm run check    # 无浏览器的逻辑自检（城市生成、通勤模拟、规划助手）
```

线上版本由 Cloudflare Pages 从 `main` 自动构建发布。包括 three.js 在内的一切都内联在那一个文件里，不依赖任何 CDN，离线也能玩。

## 规划助手与广告

规划助手需要看一段约 30 秒的广告来解锁，一次解锁 30 分钟。设置在 `index.html` 里的 `window.MC_ADS`：

| 字段 | 作用 |
|---|---|
| `enabled` | `false` 关闭整个机制，助手免费 |
| `provider` | `'house'`：内置的 30 秒提示卡片（占位，不需要广告账号）；`'adsense'`：Google H5 游戏广告的激励广告 |
| `client` | AdSense 发布商 ID（`ca-pub-…`），`provider` 为 `'adsense'` 时必填 |
| `seconds` / `unlockMinutes` | 占位卡片时长 / 一次解锁的分钟数 |
| `test` | `true` 时向 Google 请求测试广告（开发时务必打开） |

只有广告完整看完才解锁；玩家每次都要自己点"看广告"，不会自动播放；没有可用广告时直接放行，不会把人锁在外面。

## 代码结构

```
index.html              页面骨架（面板、工具栏、弹窗）
src/main.js             入口：样式 + 游戏
src/styles.css          全部样式
src/game/
  core/                 常量、三语文案、工具函数、城市生成（地形、河流、道路骨架、人口）
  sim/                  线网与换乘、通勤模拟、人口迁移、街道网生长、设施与项目、
                        快线、规划助手与线路规划器、城市委托
  ui/                   地图绘制与图层缓存、相机、画线与输入、面板与报告、成就、存档、
                        建筑生成、观景模式、3D 视角、背景音乐、城市委托、常识自检
scripts/game-scope.js   Vite 插件：把 src/game 拼成一个模块
scripts/smoke.mjs       npm run check 用的自检脚本
```

游戏的各个文件共享同一个作用域（城市、线网和模拟处处要读写），所以 `game-scope.js` 按文件夹顺序（core → sim → ui）、再按文件名开头的编号，把它们拼成一个 ES 模块。新增文件时，给它一个排在所有依赖之后的编号即可。

浏览器控制台里有一个小调试接口 `window.__mc`（`__mc.newCity(seed)`、`__mc.adoptTop()` 等）。
